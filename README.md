# 🔐 Password Strength Checker

## 📌 Project Overview

**Password Strength Checker** is a Python-based cybersecurity project designed to evaluate the strength and security of a password. The program analyzes different password characteristics such as length, uppercase and lowercase letters, numbers, special characters, and common password patterns.

The system classifies passwords into **Weak, Medium, Strong, or Very Strong** categories and provides suggestions to help users create more secure passwords.

## 🎯 Project Purpose

The main purpose of this project is to help users understand password security and identify weak passwords before using them for online accounts.

## 🔄 How It Works

1. The user enters a password.
2. The program checks the password length.
3. It checks for uppercase and lowercase letters.
4. It checks for numbers.
5. It checks for special characters.
6. It identifies simple or predictable patterns.
7. A strength score is calculated.
8. The password is classified as Weak, Medium, Strong, or Very Strong.
9. The program displays suggestions for improving the password.

## ▶️ How to Run

Make sure Python is installed on your computer.

### Step 2: Open the Project

Open the project folder in **VS Code**.

Open the VS Code terminal and run:
